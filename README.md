# Sistema de Registro de Estudiantes

Aplicación web simple para registrar y gestionar estudiantes.

## Funcionalidades

- Registro de estudiantes
- Búsqueda de estudiantes
- Eliminación de registros
- Almacenamiento de datos mediante LocalStorage

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Uso

Para utilizar el proyecto solo es necesario abrir el archivo index.html en un navegador.
